# 依恋类型 · 恋爱风格测试

24 道题、约 4 分钟的 H5 测试。测出你在亲密关系里的依恋类型：8 种恋爱风格、焦虑 / 回避 / 外显三维分布、相处契合与易耗类型，完整报告与结果海报全部免费。

## 运行

纯静态页面，无构建步骤、无第三方依赖。

- 直接双击 `index.html` 即可打开；
- 或在目录内启动本地服务：`python -m http.server 8000`，访问 `http://localhost:8000`。

`audio/` 目录必须与 `index.html` 同级，否则点击音效与背景音乐不会播放。

## 目录结构

```
index.html            全部页面（样式、脚本、题目与结果文案均内联）
audio/click.mp3       选项点击 / 上一题音效
audio/complete.mp3    答完所有题的提示音
audio/bgm-quiz.mp3    首页与答题流程背景音乐
audio/bgm-result.mp3  结果页背景音乐
```

## 部署

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支、目录选 `/ (root)`，保存后即可访问。
- **Netlify / Vercel**：直接将本文件夹拖入即可，无需填写构建命令与输出目录。
- **自有服务器（Nginx 等）**：把本文件夹里的内容整体放到站点根目录。

## 说明

背景音乐默认静音，右下角按钮手动开启，开关状态记录在 `localStorage`；页面切换时自动淡入淡出。
测评结果仅供自我觉察与娱乐参考，不构成心理诊断或医疗建议。
